Tentang Bakmi Mulia

Portal belajar dan berdiskusi tentang dunia desain web.

Apa itu Bakmi Mulia?

Bakmi Mulia adalah portal belajar dan komunitas diskusi seputar desain web. Nama ini terinspirasi dari bakmi — makanan yang sederhana tapi bisa dinikmati bareng-bareng — dan "mulia" yang berarti bermartabat. Kami percaya belajar coding juga bisa santai, menyenangkan, dan saling menguatkan.

Fokus kami: HTML, CSS, JavaScript, dan JSON — fondasi yang wajib dikuasai sebelum masuk ke framework. Ditambah praktik deploy ke GitHub Pages biar project kamu langsung live.

Fitur Portal

  • ✅ Materi terstruktur — HTML, CSS, JS, JSON, dan Deploy
  • ✅ Forum diskusi — tanya jawab santai antar pembelajar
  • ✅ Showcase karya — inspirasi dari project komunitas
  • ✅ Konten berbasis JSON — praktik real cara load data di static site
  • ✅ Siap deploy GitHub Pages — tinggal push, langsung live
  • ✅ Desain modern minimalis — dark theme dengan brand burgundy & gold

Tech Stack

Website ini dibangun pure static — tanpa framework, tanpa backend. Cocok banget buat belajar fondasi:

HTML5 CSS3 Vanilla JavaScript JSON GitHub Pages

Cara Deploy ke GitHub Pages

  1. Buat repository baru di GitHub (misal: bakmi-mulia)
  2. Upload semua file project ini ke repo tersebut
  3. Buka Settings → Pages
  4. Pilih branch main (atau master) sebagai source
  5. Klik Save — website kamu live di https://username.github.io/bakmi-mulia/

Tip: pastikan path di HTML/CSS/JS menggunakan relative path (sudah disiapkan di project ini).
